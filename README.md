# claudecode-harness-em-patterns

Claude Code を使った開発ハーネスの設計パターン集 — **エンジニアリングマネージャー（EM）個人のプロジェクト管理向け**。

複数プロジェクトを抱える EM が、Claude Code を「自分専用のプロジェクト管理ハーネス」として使うための観点を扱う:

- 複数プロジェクト/リポジトリの進捗の集約・把握（自分用サマリ生成）
- リスク・ブロッカーの早期検知（放置タスク、遅延兆候の抽出）
- 意思決定支援（優先順位付け、トレードオフの整理）
- ステークホルダー向け報告の下書き支援（週報・ステータス更新・1on1準備）
- 自分自身のタスク/委譲管理

## 構成

- `patterns/` — ケース別の設計パターン（README形式）
- `research/` — 調査ノート（一次資料への参照を含む）

## スコープ外

- チームへのハーネス展開・チームメンバーへの権限付与・オンボーディング
- 個別のコードレビュー観点やパターンの技術的詳細（→ `claudecode-harness-patterns`）
- Ryoko 自身の運用環境の改善（→ harness-ops）
