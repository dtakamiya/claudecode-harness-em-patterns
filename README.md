# claudecode-harness-em-patterns

Claude Code を使った開発ハーネスの設計パターン集 — **エンジニアリングマネージャー（EM）向け**。

EM がチームに Claude Code ハーネスを導入・運用する際に必要な観点を扱う:

- 進捗の可視化（ボード連携・レポーティング）
- 権限設計・承認ゲート（誰が何を自動化してよいか）
- チームへの展開・オンボーディング手順
- コスト/利用状況の追跡
- 委譲・レビュー体制のガバナンス（TRUST / VERIFY / THOROUGH の運用）

## 構成

- `patterns/` — ケース別の設計パターン（README形式）
- `research/` — 調査ノート（一次資料への参照を含む）

## スコープ外

- 個別のコードレビュー観点やパターンの技術的詳細（→ `claudecode-harness-patterns`）
- Ryoko 自身の運用環境の改善（→ harness-ops）
